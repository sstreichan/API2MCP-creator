# Codebase Structure

```

│       ├── qs.ts                 # Query string utilities
│       ├── retry.ts              # Retry logic
│       └── logger.ts             # Structured logging
│
├── test/                          # Test suite
│   └── server.smoke.test.ts      # Smoke test for MCP server
│
├── scripts/                       # API automation scripts
│   ├── _load_env.ts              # .env.local loader
│   ├── discover_openapi.ts       # OpenAPI discovery script
│   ├── inventory_api.ts          # One-command API inventory
│   ├── oauth2_client.ts           # OAuth2 client credentials flow
│   ├── oauth2_device.ts           # OAuth2 device code flow
│   ├── openapi_to_tools.ts       # OpenAPI to tools.json converter
│   ├── probe_get.ts              # Throttled GET probe
│   ├── scan_to_tools.ts           # Wordlist scan to tools.json
│   ├── scan_wordlist.ts           # OPTIONS wordlist scanner
│   └── validate_endpoints.ts    # Safe endpoint validation
│
├── examples/                      # Example configurations
│   └── hexnode.tools.json        # Example tools.json for Hexnode API

├── internal/                      # Internal utilities and extensions

│   ├── config/                   # Configuration management
│   ├── devtools/                 # Development tools
│   ├── httpx/                    # Enhanced HTTP client
│   ├── logging/                  # Advanced logging
│   ├── mcp/                      # MCP extensions
│   └── tools/                    # Tool utilities
│
├── dist/                          # Compiled TypeScript output
├── .github/                      # GitHub Actions workflows
│   └── workflows/               # CI/CD definitions
├── .cortexkit/                    # Magic context system
├── .tokensave/                    # Tokensave knowledge graph
└── docs/                          # Documentation (if any)
```

## Directory Purposes

**src/:**
- Purpose: Main application source code
- Contains: TypeScript source files with MCP server implementation
- Key files: server.ts (entrypoint), lib/ (helpers)

**test/:**
- Purpose: Test suite for the MCP server
- Contains: Integration tests, smoke tests
- Key files: server.smoke.test.ts

**scripts/:**
- Purpose: API discovery and automation utilities
- Contains: Command-line scripts for API onboarding
- Key files: discover_openapi.ts, inventory_api.ts, oauth2_*.ts

**examples/:**
- Purpose: Sample configurations and tool definitions
- Contains: Pre-built tools.json examples
- Key files: hexnode.tools.json

**internal/:**
- Purpose: Internal utilities and extensions
- Contains: CLI tools, config management, HTTP enhancements
- Key files: various subdirectories with specialized tools

**dist/:**
- Purpose: Compiled TypeScript output
- Contains: Generated JavaScript files for production
- Key files: server.js (compiled from src/server.ts)

**docs/:**
- Purpose: Additional documentation
- Contains: Architecture and structure documentation

## Key File Locations

**Entry Points:**
`src/server.ts`: MCP server entrypoint registers core tools (api_probe, api_get, api_post, api_put, api_delete)

**Configuration:**
`scripts/_load_env.ts`: Minimal .env.local loader used by scripts

**Core Logic:**
`src/server.ts`: Main HTTP API adapter with typed tool handlers
`src/lib/qs.ts`: Query string serializer (filters empty values)
`src/lib/retry.ts`: Exponential backoff retry with jitter
`src/lib/logger.ts`: JSON logger with URL token redaction

**Tests:**
`test/server.smoke.test.ts`: Spawns server over stdio transport, validates core tools

## Naming Conventions

**Files:**
- Pattern: kebab-case for scripts, lowercase for .ts files
- Example: discover_openapi.ts, oauth2_client.ts, validate_endpoints.ts

**Directories:**
- Pattern: lowercase with underscores
- Example: src/lib/, scripts/, internal/cli/

**Environment Variables:**
- Pattern: UPPER_SNAKE_CASE
- Examples: API_BASE, AUTH_MODE, AUTH_TOKEN, ALLOW_DESTRUCTIVE

## Where to Add New Code

**New tool:**
- Place in `src/server.ts` as a new server.tool() registration
- Or create dynamic tool via `tools.json` (generated by scripts)

**New helper:**
- Add to `src/lib/` directory (qs.ts, retry.ts, logger.ts pattern)
- Export with named export, no default exports

**New script:**
- Add to `scripts/` directory
- Follow existing pattern: env loading at top, action in main

**New MCP extension:**
- Add to `internal/mcp/` directory

**New test:**
- Add to `test/` directory
- Co-located with source: e.g., test for server.ts in test/server.smoke.test.ts

**Configuration:**
- Use `.env.local` for runtime configuration
- Environment variables must be UPPER_SNAKE_CASE
